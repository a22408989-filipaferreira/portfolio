Utilização do GitHub

O GitHub foi utilizado para armazenar, versionar e acompanhar a evolução do projeto Portfolio desenvolvido em Django. Ao longo do desenvolvimento, foram realizados commits com as alterações implementadas, permitindo manter um histórico do trabalho realizado.

Vantagens

Esta tecnologia permite controlar versões do código, recuperar alterações anteriores, trabalhar de forma mais organizada e manter o projeto disponível remotamente. Também facilita a entrega do projeto e a integração com ferramentas de deployment e CI/CD.
